# ⚡ 채팅 도우미 C# .NET 8 네이티브 버전

파이썬의 지연 및 랙 현상을 100% 극복한 **초경량(200KB) · Zero-Lag(0ms) · 무포커스 윈도우 네이티브 채팅 도우미**입니다.

---

## 🌟 핵심 특징 & 개선점

1. **타이핑 지연 0.000ms (완전한 무랙)**:
   - 윈도우 OS 저수준 키보드 훅(`WH_KEYBOARD_LL`)을 네이티브로 다루어, 아무리 빠르게 타자를 쳐도 **키가 밀리거나 버벅거리지 않습니다.**
2. **채팅 방해 방지 안전 트리거 시스템**:
   - 일반 채팅이나 들여쓰기 시 사용하는 **일반 `Tab` 키는 100% 정상 작동**합니다.
   - 자동완성은 **트리거 키(기본값: `\`, 설정에서 변경 가능)**와 조합할 때만 반응합니다:
     - `\ㅇㄴ` 치면 ➔ 즉시 전체 문장으로 자동 치환
     - 커서 옆에 추천 칩이 떴을 때 **`\ + Tab`** ➔ 추천 문장으로 즉시 완성
     - 커서 옆에 추천 칩이 떴을 때 **`\ + 1`**, **`\ + 2`**, **`\ + 3`** ➔ 해당 번호 문장 완성
3. **스마트폰 스타일 커서 실시간 추적**:
   - 카카오톡, 메모장, 브라우저 어디서든 글을 쓰는 커서 바로 옆에 슬림한 알약 칩이 살포시 따라다닙니다.
   - 포커스를 절대 뺏지 않는 `WS_EX_NOACTIVATE` 윈도우로 동작합니다.
4. **구글 스프레드시트 CSV 연동**:
   - 스프레드시트의 '웹에 게시' CSV 링크를 등록하면 0.05초 만에 최신 템플릿으로 실시간 동기화됩니다.

## ⚙️ 설정 변경 방법

1. 화면 우측 하단 트레이의 아이콘 우클릭 ➔ **[⚙️ 자동완성 모드 설정...]** 클릭
2. **트리거 접두사 키 변경**: 기본값 `\`를 원하는 특수문자나 키로 자유롭게 변경 가능
3. **모드 비교**:
   - **옵션 1: 스마트폰 인라인 툴팁 (단일 알약 칩)**
   - **옵션 2: 가로형 미니 추천 바 (3개 가로 나열)**
   - **옵션 3: 수동 단축키 모드 (Alt + Q)**
4. **구글 시트 연동**: CSV URL 입력 후 즉시 동기화 버튼 클릭!
