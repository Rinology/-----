# 💬 윈도우 채팅 도우미 (Chat Helper) v3

스마트폰처럼 **타이핑 중인 커서 바로 옆에 추천 바가 실시간으로 따라다니고**, `Tab` 키 한 번으로 문장이 쏙 완성되는 지능형 윈도우 채팅 도우미입니다.

---

## 📱 2가지 자동완성 옵션 비교 & 설정

트레이 아이콘(우측 하단 파란색 [C])을 우클릭하고 **[⚙️ 자동완성 모드 설정...]**을 누르면 실시간으로 모드를 변경해 비교해 보실 수 있습니다.

| 모드 | 동작 모습 | 완성 방법 | 특징 |
| :--- | :--- | :--- | :--- |
| **옵션 1: 스마트폰 인라인 툴팁 (기본)** | 글을 칠 때 커서 바로 옆에 `[Tab] 추천문구` 알약 칩이 살짝 따라다님 | **`Tab` 키** 또는 마우스 클릭 | 화면을 전혀 가리지 않고 깔끔하며, 마음에 들 때만 `Tab`으로 쏙 입력 |
| **옵션 2: 가로형 미니 추천 바** | 스마트폰 키보드처럼 커서 위에 2~3개의 추천 후보가 가로로 나열됨 | **`Tab` (1번)** 또는 마우스 클릭 | 여러 후보 중 원하는 것을 직접 골라 쓰고 싶을 때 유용 |
| **옵션 3: 수동 단축키 모드** | 타이핑 중에는 조용히 숨어있음 | **`Alt + Q`** 눌렀을 때만 커서 옆에 팝업 | 타이핑 중 방해를 완전히 끄고 원할 때만 호출 |

---

## ⚡ 즉시 단축어 치환 (Text Expansion)

메뉴를 보지 않고도 채팅창에서 평소 쓰듯 입력하면 즉시 긴 문장으로 치환됩니다:
- `\ㅇㄴ` ➔ `안녕하세요! 문의주셔서 감사합니다. 무엇을 도와드릴까요?`
- `\ㄱㅅ` ➔ `감사합니다. 추가로 궁금하신 점 있으시면 언제든 말씀해 주세요! :)`
- `\ㄱㅈ` ➔ 카카오뱅크 입금 계좌 안내문
- `\ㅈㅅ` ➔ 죄송합니다 안내문
- `\ㅅㄱ` ➔ 수고하셨습니다 안내문

## 🚀 빠른 시작

1. [run.bat](file:///c:/Users/taerin/Desktop/채팅도우미/run.bat) 더블클릭 (또는 [start_silent.vbs](file:///c:/Users/taerin/Desktop/채팅도우미/start_silent.vbs)로 무음 실행)
2. 메모장이나 카카오톡에서 `ㅇ` 또는 `ㅇㄴ`를 쳐보세요:
   - 커서 바로 옆에 `Tab ↵` 알약 칩이 뜹니다.
   - **`Tab` 키**를 누르면 문장이 즉시 입력됩니다!
3. 우측 하단 트레이의 **파란색 [C] 아이콘** 우클릭 ➔ **[⚙️ 자동완성 모드 설정...]**을 열어 **옵션 1**과 **옵션 2**를 비교해 보세요.
