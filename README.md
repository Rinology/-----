# 💻 ChatHelper v2.0 (Windows 98 Millennium Edition)

파이썬의 타이핑 지연을 완전히 극복한 **초경량 C# .NET 8 네이티브 · Zero-Lag(0ms) · 스마트폰형 커서 추적 채팅 도우미**입니다.

---

## 🌟 주요 기능 및 해결된 사항

1. **화면 상태표시창 & 작업표시줄 실행 상태 표시**:
   - 실행 시 화면 우측 하단 및 작업표시줄에 **`🟢 ChatHelper v2.0 ME - 실행 중`** 상태바가 항상 표시되어 작동 여부를 한눈에 확인할 수 있습니다.
   - 상태바에서 **[💻 제어판 열기]**, **[🔍 검색(Alt+Q)]**, **[⏸️ 일시정지]**, **[🔽 트레이이동]** 버튼을 클릭 한 번으로 조작할 수 있습니다.
   - (제어판 설정에서 작업표시줄 표시 vs 트레이 아이콘으로만 숨기기 선택 가능)
2. **비입력 화면 오작동 완전 차단 (스마트 필터링)**:
   - `Ctrl+C`, `Ctrl+V`, `Ctrl+A`, `Ctrl+S` 등 단축키 조합 입력 시 추천 알약이 뜨지 않도록 필터링합니다.
   - 바탕화면, 작업표시줄, 제어판 내부, 방향키 이동 시 알약을 즉시 숨기며, 타이핑이 멈추면 **3.5초 뒤 자동으로 사라집니다.**
   - 최소 2글자 이상 유효한 단축어가 입력되었을 때만 정확하게 추천 알약이 뜹니다.
3. **자연스러운 스마트폰 스타일 자동완성**:
   - 평소처럼 한글 모드 그대로 **`ㅇㄴ`** (물리키 `ds`), **`ㅂㅅ`** (물리키 `qt`), **`ㄱㅈ`** (물리키 `rw`) 등을 치면 커서 옆에 추천 알약이 뜹니다.
   - 마음에 들면 **`\ + Tab`** (또는 `\` 누른 직후 `Tab`)을 눌러 0.01초 만에 문장을 완성합니다.
   - 일반 `Tab` 키는 100% 본래 기능(들여쓰기/이동)대로 정상 작동합니다.
4. **윈도우 98 레트로 제어판 & 스프레드시트 로그인**:
   - **커맨드 관리**: 프로그램 안에서 자주 쓰는 말 추가/수정/삭제 (실전 CS 템플릿 50개 기본 탑재)
   - **단축키 충돌 검사**: 윈도우 기본 단축키(`Alt+Tab`, `Ctrl+C` 등)와 겹치면 실시간 경고 표시
   - **디자인 테마**: `Windows 98 ME`, `Modern Dark`, `Modern Light` 3종 테마 지원
   - **라이선스 인증**: 구글 시트(또는 `users.csv`)의 아이디 및 만료일 기반 로그온 검증
