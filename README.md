## 🌟 주요 기능

### 1. ⚡ 한글/영문 실시간 키워드 & 초성 자동완성
- 채팅창에서 평소처럼 단축어(예: `\ed`)나 한글 키워드·초성(예: `ㅎㅂ` → 환불)을 입력하면 추천 알약이 즉시 표시됩니다.
- **`\ + Tab`**(또는 설정한 완성키 / 번호 선택)으로 0.01초 만에 정해진 답변 문구로 치환합니다.
- **윈도우 한글 IME 상태 머신(`HangulImeBuffer`)** 탑재로 글자 조합 중 백스페이스와 완성 음절 백스페이스를 정확히 구분합니다.
- **사칙연산 자동 계산**: `5 * 10 =` 입력 시 `50`을 즉시 계산해 추천합니다.

### 2. 🎯 채팅 텍스트 커서(Caret) 정밀 추적 (+ 마우스 포인터 옵션)
- 기본값으로 마우스 포인터가 아닌 **실제 채팅 입력 커서(Caret)** 위치(Win32 Caret + MSAA `OBJID_CARET` + 한글 IME 조합 커서)에 추천 알약을 띄웁니다.
- 사용자 취향에 따라 **제어판 > 🎨 디자인 & 표시**에서 **채팅(키보드) 커서 기준**, **마우스 포인터 위치 기준**, **우측 하단 고정** 중 선택할 수 있습니다.

### 3. 🔍 빠른 검색 (`Alt + Q`) & ⭐ 최근 사용 고정
- `Alt + Q`로 전체 템플릿을 키워드·카테고리(`Tab` / `Shift+Tab`)별로 빠르게 검색하고 `Enter`로 즉시 입력합니다.
- 최근 사용한 템플릿(최대 10개)이 목록 최상단에 자동 고정되며 **`⭐ 최근 사용`** 탭으로 모아볼 수 있습니다.

### 4. ✨ 특수기호 전용 창 (`Alt + X`)
- `Alt + X`를 누르면 특수기호·이모티콘 전용 창(`→`, `■`, `★`, `✔` 등)이 열립니다.
- **`Alt` 없이 숫자키 `1`~`9` 단독 입력**(GeForce 등 외부 단축키 충돌 없음) 또는 **`←↑↓→` + `Enter`**로 즉시 입력합니다.
- 하단 입력칸에서 사용자가 원하는 특수문자나 이모티콘을 직접 **추가 / 선택삭제 / 기본값 복원**할 수 있습니다.

### 5. 🌐 드래그 선택 양방향 번역 (`Alt + T`) · 🧩 `Xenie` & `챗헬프 임시메모` (`Alt+N` / `\+M` / `\+V` / `\+N`) · 🗂 업무 프로필 전환
- **드래그 선택 Google 양방향 번역 (`Alt + T`)**: 번역할 문장을 마우스로 드래그해 선택한 뒤 **`Alt + T`**를 누르면 선택한 원문 미리보기와 **로딩 프로그레스 바**가 뜨고, 번역 완료 후 원문 ↔ 번역 비교 카드에서 **`선택 영역 바꾸기`** / **`원문+번역 함께 입력`** / **`복사`** / **`⇄ 한↔영 다시 번역`**을 바로 실행할 수 있습니다. (**제어판 > 단축키 & 동작**에서 `자동 감지(한↔영)` · `한글 → 영문` · `영문 → 한글` 선택 가능)
- **챗헬프 임시메모 & Xenie 답변 조합기 (`Alt+N` / `\+M` / `\+V` / `\+N`)**:
  - **`챗헬프 임시메모` (`Alt+N`)**: 복사한 송장번호·날짜·이미지 OCR(`\+V`)이나 채팅 키워드(`\+M`)를 가볍게 모아두며, `📦 송장`·`📅 날짜`·`💰 금액` 이름표 자동 인식 및 여러 줄 메모 `줄나누기`를 지원합니다.
  - **`Xenie` (`\+N`)**: 누적 키워드 좁히기와 블록 조합, `{송장번호}`/`{날짜}` 원클릭 빈칸 채우기 후 **`\+F`** 또는 **`Ctrl+Shift+Enter`**로 최종 문장을 입력합니다. 두 창은 `🔗` 자석 도킹 및 화면 가장자리 스냅으로 나란히 붙여 사용할 수 있습니다.
- **업무 프로필 1클릭 전환 & 유저 개인 시트 추가/삭제**: 메인 도킹 바에서 공용 시트(`물류`, `CS상담` 등)를 전환하거나, **제어판 > `🗂 데이터 소스`**에서 본인 전용 시트를 **`☁️ GAS 클라우드(내 계정 로밍)`** 또는 **`💻 로컬 PC 전용`**으로 직접 추가·삭제할 수 있습니다. (GAS `프로필목록` 탭 기반으로 본인 소유 시트만 안전하게 관리)
- **로컬 보안 & 배포 분리**: 사용자 설정(`config.json`, DPAPI 암호화)과 7일 자동 삭제 로그(`logs/`)는 `%LocalAppData%\ChatHelper\`에 분리 저장되어 `publish/` 폴더 압축 배포 시 개인 ID나 로그가 유출되지 않습니다.
- **1클릭 동기화 & 실시간 로그**: 메인 상태창의 `시트 [...]` 클릭 시 즉시 동기화되며, **`로그`** 버튼을 누르면 불러오기·로그인 기록 상태를 실시간으로 확인할 수 있습니다.

## 🚀 빌드 및 실행 방법 (`publish/` 단일 표준)

> C# .NET 관례에 따라 빌드 및 실행 경로는 **`publish/`** 하나로 통일합니다. (과거 Python 시절의 `dist/` 폴더는 사용하지 않습니다.)

### 1. 바로 실행
- [publish/ChatHelper.exe](file:///C:/Users/taerin/Desktop/채팅도우미/publish/ChatHelper.exe) 실행 (직원 배포 시 `.env` 파일 불필요)

### 2. 다른 컴퓨터에서 `git pull` 후 동일하게 빌드하기
```powershell
# 1) 최초 pull 직후 (NuGet 패키지 복원 포함 빌드)
dotnet publish ChatHelper\ChatHelper.csproj -c Release -o publish

# 2) 이후 코드 수정 시 빠른 재빌드
dotnet publish ChatHelper\ChatHelper.csproj -c Release --no-restore -o publish
```

### 3. 단위 테스트 실행
```powershell
dotnet run --project ChatHelper.Tests\ChatHelper.Tests.csproj
```
