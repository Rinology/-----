# 💬 윈도우 채팅 도우미 (Chat Helper)

작업/채팅(카카오톡, 슬랙, 디스코드, 웹 브라우저, 메모장 등) 중 방해받지 않고, **단축키 하나로 자주 쓰는 말을 검색하여 즉시 입력(자동완성)**해 주는 윈도우 전용 데스크톱 프로그램입니다.

---

## 🚀 빠른 시작

1. **실행하기**
   - **콘솔 확인용**: [run.bat](file:///c:/Users/taerin/Desktop/채팅도우미/run.bat) 더블클릭 (로그 출력)
   - **무음 백그라운드 실행**: [start_silent.vbs](file:///c:/Users/taerin/Desktop/채팅도우미/start_silent.vbs) 더블클릭 (까만 콘솔 창 없이 트레이로만 실행)
2. **단축키 누르기**
   - 어디서든 **`Alt + Q`**를 누르면 화면 중앙에 플로팅 검색창이 뜹니다.
3. **입력 & 자동 완성**
   - 키워드(예: `인사`, `계좌`, `주소`) 또는 내용을 입력합니다.
   - **`↑` / `↓` 방향키**로 이동 후 **`Enter`**를 누르면 원래 채팅창에 바로 붙여넣어집니다.
   - 취소하려면 **`Esc`**를 누릅니다.

---

## 📋 키 조작 안내

| 조작 | 기능 |
| :--- | :--- |
| **`Alt + Q`** | 제안 오버레이 열기 / 닫기 (토글) |
| **텍스트 입력** | 실시간 다중 단어 검색 (키워드/제목/내용) |
| **`↑` / `↓`** | 제안 목록 항목 이동 |
| **`Enter`** | 선택한 항목을 이전 작업창에 자동 붙여넣기 후 창 닫기 |
| **`Esc`** | 붙여넣기 없이 닫기 |
| **`Ctrl + R`** | CSV 템플릿 즉시 다시 불러오기 |

## 📊 구글 스프레드시트 CSV 연동 방법 (원격 배포)

팀원들과 자주 쓰는 말을 공유하거나 스프레드시트에서 편리하게 수정하여 배포할 수 있습니다.

1. **구글 스프레드시트 작성**:
   - 첫 행 헤더: `keyword`, `title`, `content`, `category`
2. **웹에 CSV로 게시**:
   - 스프레드시트 상단 메뉴: **[파일] → [공유] → [웹에 게시]**
   - [전체 문서] 또는 [시트1] 선택 후, 형식을 **[웹페이지] 대신 [쉼표로 구분된 값(.csv)]**으로 선택
   - **[게시]** 버튼을 누르고 나오는 URL 링크를 복사
3. **설정 파일에 등록**:
   - [config.json](file:///c:/Users/taerin/Desktop/채팅도우미/config.json)을 열고 `"remote_csv_url"`에 복사한 링크를 입력
4. **동기화**:
   - 화면 우측 하단 작업표시줄 트레이의 파란색 **[C]** 아이콘을 우클릭하고 **[구글 시트에서 최신 동기화]** 클릭!

---

## ⚙️ 설정 파일 (`config.json`)

```json
{
  "hotkey": "<alt>+q",
  "csv_file": "chat_templates.csv",
  "remote_csv_url": "",
  "restore_clipboard": true,
  "paste_delay_ms": 70
}
```
- `hotkey`: 단축키 변경 (예: `<ctrl>+<shift>+v`, `<alt>+space` 등)
- `restore_clipboard`: 붙여넣기 후 원래 복사해뒀던 클립보드 내용을 복원할지 여부 (`true`/`false`)
- `paste_delay_ms`: 창 포커스 복원 후 키 입력 대기 시간 (밀리초)
