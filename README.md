# 💬 윈도우 채팅 도우미 (Chat Helper) v2

작업/채팅(카카오톡, 슬랙, 디스코드, 웹 브라우저, 메모장 등) 중 **스마트폰처럼 입력 중인 커서 바로 옆에 제안 창이 따라다니고**, **초성 단축어(예: `\ㅇㄴ`) 입력 시 즉시 문장이 완성**되는 지능형 윈도우 데스크톱 도우미입니다.

---

## 🌟 핵심 개선 기능

1. **스마트폰 스타일 커서 추적 오버레이**:
   - 화면 중앙이 아니라, **현재 글을 쓰고 있는 텍스트 커서(또는 마우스) 바로 아래**에 컴팩트한 제안 창이 뜹니다.
   - 단축키: **`Alt + Q`**
2. **키보드 완성 후 자연스러운 전송/줄바꿈**:
   - `Enter`를 1번 누르면: 제안된 문장이 즉시 자동완성됨.
   - 그 상태에서 `Enter`를 1번 더 누르면: 카카오톡 등의 **[메시지 전송]** 동작.
   - `Shift + Enter`를 누르면: **[줄바꿈]** 동작.
3. **단축어 자동 치환 (Text Expansion)**:
   - 마우스나 메뉴를 열지 않고도 채팅창에서 바로 입력:
     - `\ㅇㄴ` 입력 시 ➔ `안녕하세요! 문의주셔서 감사합니다. 무엇을 도와드릴까요?` 자동완성
     - `\ㄱㅅ` 입력 시 ➔ `감사합니다. 추가로 궁금하신 점 있으시면 언제든 말씀해 주세요! :)` 자동완성
     - `\ㄱㅈ` 입력 시 ➔ 계좌번호 안내문 자동완성
     - `\ㅈㅅ` 입력 시 ➔ 죄송합니다 안내문 자동완성
   - (단축어 트리거 접두사 `\`는 `config.json`에서 자유롭게 변경 가능)

## ⌨️ 키 조작 안내

| 기능 | 조작법 |
| :--- | :--- |
| **커서 옆 제안 창 열기** | **`Alt + Q`** (현재 입력 커서 바로 아래에 팝업) |
| **빠른 숫자 선택** | **`1` ~ `9`** 키를 누르면 해당 번호 항목 즉시 완성 |
| **방향키 탐색** | **`↑` / `↓`** 방향키로 항목 이동 후 **`Enter`** |
| **즉시 단축어 치환** | 채팅창에서 **`\ㅇㄴ`**, **`\ㄱㅅ`**, **`\ㄱㅈ`** 등 입력 시 즉시 전체 문장 치환 |
| **창 닫기** | **`Esc`** |
| **템플릿 새로고침** | **`Ctrl + R`** (제안 창 열린 상태에서) |

## 📊 구글 스프레드시트 CSV 연동 (원격 배포)

1. 구글 시트 작성: `keyword`, `title`, `content`, `category`
2. **[파일] → [공유] → [웹에 게시] → [쉼표로 구분된 값(.csv)]** 선택 후 게시 링크 복사
3. [config.json](file:///c:/Users/taerin/Desktop/채팅도우미/config.json)의 `"remote_csv_url"`에 링크 붙여넣기
4. 트레이 아이콘 우클릭 ➔ **[구글 시트에서 최신 동기화]** 클릭!
